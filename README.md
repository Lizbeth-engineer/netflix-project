# Netflix Data Analysis Dashboard

Aplicación interactiva desarrollada con Streamlit para el análisis exploratorio de datos del catálogo de Netflix.

## Descripción

Este proyecto permite visualizar y analizar información de contenido de Netflix a través de una interfaz interactiva.  
El usuario puede cargar el dataset en formato CSV (adjuntado) y explorar diferentes métricas y visualizaciones.

---

## Características

- Carga dinámica de archivos CSV
- Análisis exploratorio de datos (EDA)
- Visualizaciones interactivas
- Exploración de variables como:
  - Tipo de contenido (películas/series)
  - País
  - Año de lanzamiento
  - Géneros

## Tecnologías utilizadas

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib

## Resultados principales

- La mayoría del contenido en Netflix corresponde a películas
- Estados Unidos es el país con mayor cantidad de títulos
- El contenido ha aumentado significativamente a partir de 2015
- Los géneros más frecuentes son Drama y Comedia
